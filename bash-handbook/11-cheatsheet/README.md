# 第 11 章 · 全书速查：出活时翻的这一页

> 前十章是把道理**演**给你看，这一章是你**以后每天上班翻**的那一页。
> 所以它的写法不一样：**没有大段解释，只有「你要干什么 → 靠得住的写法 → 现场在哪一章」。**
>
> 这一章不新跑取证脚本。表里每一行都指回前十章某一节真跑过的现场，出处写在最后一列；
> 不信、或者忘了为什么，就按出处回去看那一段屏幕输出。
> 唯一当场跑的东西在本章自己的 `demo.sh` 里 —— 它把枪口对准**这一页本身**：
> 出处有没有断链、给出的 `bash` 片段过不过得了 `bash -n`、几条硬事实现在还在不在。

---

## 你会遇到的场景

- 写到 `if` 那一行，不确定 `[ "$x" = 1 ]` 的引号要不要加 → **表 2**。
- 抄了一段网上的 `find … | xargs rm`，不敢按回车 → **表 3** + **表 7**。
- 你的 `while read` 循环莫名其妙只跑了一半 → **表 4**。
- 想给脚本套 `set -Eeuo pipefail`，怕它把正常流程也杀了 → **表 7**。
- 脚本在同事机器上退 127，不知道是谁的锅 → **表 8** + **表 10**。
- 只想在电梯里说清这章讲了啥 → **一页纸（22 条）**。

## 怎么用这一章（四条规矩）

1. **出处记法**：`03 §9` = 第 03 章第 9 节（就是那章 README 里的 `## 9. 标题`）；
   第 01、02 两章按标题分节、没有编号，所以写成 `02 §「六道工序」` 这种带引号的样子，
   引号里是那节标题里出现过的字。`demo.sh` 第 3 节把这一页里**每一条**出处都解析一遍，
   落在哪一章、那一节在不在，全数出来 —— 断一条就报一条。
2. **表里没有的写法，多半是本书故意没给的。** 比如「用 `$*` 转发参数」「`sh x.sh` 试 bash 脚本」
   「`sed -i ""`」—— 它们都出现在各章的坑清单里，别从这一页反过来猜「应该也可以吧」。
3. **这一页的守卫全部能响**。`demo.sh` 每条断言在报 0 之前，都先被人为弄坏一次
   （改一个不存在的章节号、塞一段缺 `fi` 的片段、往副本里插一条真用户名），响过之后才报正常值。
   恒 0 的守卫比没有守卫更糟 —— 这是全书纪律，不是口号。
4. **「屏上」这两个字是一句可以核对的承诺，不是修辞。** 它说的是：紧跟其后的那段原文，是这台机器打出来的。
   `demo.sh` 第 3 节先把前十章的现场围栏收成一份屏幕底本（现场围栏 = 不带语言标注的围栏块，或块里真带提示词的那种；
   「怎么用这一章」下面那种让你手敲的命令不算，那是让人敲的、不是打出来的），再把本页正文和表格里的每一句回这张屏上找。
   编一句屏幕上根本没有的话，它当场就响。这条规矩反过来约束写法：反引号只用来引原文，
   要说一种**形状**（比如「$ 命令」「[退出码 N]」这种占位写法）就用「」，别拿反引号把说法冒充成打过。

## 表 1 · 变量、引用与展开（第 02 章）

| 我要…… | 靠得住的写法 | 现场 |
|---|---|---|
| 引用一个可能为空、可能带空格的值 | `"$x"` —— 不是故意省引号的，就别省 | 02 §「引用约定」 |
| 变量可能没设，给个回退 | `${x-回退}` 只判「没设」；`${x:-回退}` 连空串一起判。屏上 `v=` 那一格给的是 `[${v-兜底}] [兜底]` | 02 §「实战」第 16 节 |
| 没设就当场报错、不许往下走 | `${x?消息}`，或整脚本 `set -u`。屏上两句都响过：`UNSET_C: 未设就要停`、`NOPE: unbound variable` | 02 §「实战」第 16 节 + 08 §3 |
| 从路径里剪掉最后一段 | `${x##*/}`（最长匹配剪前缀）；留尾巴用 `${x%/*}`。屏上 `/tmp/a/b/c.tar.gz` 给的是 `[c.tar.gz]` 和 `[/tmp/a/b]` | 02 §「实战」第 17 节 |
| 数组长度 / 切片 | `${#arr[@]}` / `${arr[@]:1:2}` —— 后一个是**个数**不是结束下标，屏上 `a=(a b c d)` 切出 `<b><c>` | 02 §「实战」第 19 节 |
| 要 1..N 的序列，N 存在变量里 | **别写 `{1..$N}`**（花括号展开早于变量替换：屏上打出来是字面 `{1..3}`，序列没生成、只摊成 1 个词）→ `for ((i=1;i<=N;i++))` | 05 §6 + 02 §「实战」第 02 节 |
| 命令替换 | `$( … )`。反引号能用但嵌套要转义到没法读（屏上 `` `echo `内层` `` 与 `$(echo "$(echo 第三层)")` 各打了一次） | 02 §「实战」第 07 节 |
| 一段文本原样进变量 | 单引号；要插值就别用单引号（屏上 `echo '$v'` 原样打回 `$v`） | 02 §「实战」第 05 节 |
| 一行到底过了几道工序 | 花括号 → 波浪线 → 变量/命令/算术 → 词分割 → 通配 → 删引号。**这张六格图是正文原话（那一节 0 个带 `$ ` 的围栏）**；屏上只演了关键那一格：`$v/*.txt` 打成 `dir/one.txt dir/two.txt`，先换变量、再问文件系统 | 02 §「实战」第 02 节 |

这一表代价最高的一条：`$x` 不带引号会被**加工两次**（先按 IFS 词分割，再各做一次通配展开）。
所以「遍历一个名单」全世界只有一种写法：`"${arr[@]}"`。05 §7 用一份带空格、带 `*` 的名单，
把「加引号 / 不加 / 数组」演成三种下场。

## 表 2 · 判断与退出码（第 03 章）

| 我要…… | 靠得住的写法 | 现场 |
|---|---|---|
| 判一个命令成没成 | 直接 `if cmd; then`。别 `cmd; [ $? -eq 0 ]` —— 中间多一行就把码踩掉了 | 03 §12 |
| 文件在不在 / 是不是普通文件 / 能不能读写 | `[ -e f ]` `[ -f f ]` `[ -d d ]` `[ -r/-w/-x f ]` `[ -s f ]`（非零字节）`[ -L f ]`（是符号链接） | 03 §9 |
| 两个文件谁新、是不是同一个 | `[ a -nt b ]`、`[ a -ot b ]`、`[ a -ef b ]` | 03 §9 |
| 字符串比较 | `[ "$a" = "$b" ]`。**空值不带引号当场炸**，报错第一个字段是 `[:` | 03 §8 |
| 数值比较 | `[ "$a" -eq 3 ]` 或算术上下文 `(( a > 3 ))`；`[[ "10" < "9" ]]` 是**按字符串**比，答案是「小于」 | 03 §10 + 03 §14 |
| 模式与正则 | 只有 `[[ ]]` 里有，屏上跑过：`[[ $f == v[0-9]* ]]` → rc=0、`[[ $s =~ ^v([0-9]+) ]]` → rc=0，右半边一加引号就变 rc=1。`[ ]` 侧演过的只有「`==` 交给 dash → `dash: 1: [: abc: unexpected operator`、rc=2」；`[ … =~ … ]` 全书没演上屏 | 03 §8 + 03 §10 + 03 §13 |
| 与、或、非 | `a && b`、`a \|\| b`、`if ! cmd`；进条件位的是 `&&`/`\|\|` **左边**那一条（屏上原话「`\|\|` 左边整条都算条件位，`-e` 全程闭嘴」）。**列表最后一条**落在普通位置，它失败 `-e` 照杀：屏上 `set -e; true && false` → rc=1 | 03 §11 + 08 §5 |
| 记下某条命令的码 | 立刻 `rc=$?` 存变量；一行日志、一个 `[` 都能把它改掉 | 03 §12 |
| 一条管道里每段各自的码 | `"${PIPESTATUS[@]}"` —— `$?` 只给你最后一段 | 04 §5 |
| 什么时候**只能**用 `[ ]` | 脚本可能被 `/bin/sh`（本机 `-> dash`）跑的时候 | 03 §13 + 08 §16 |

**数字不用背一堆，背这几条就够**（03 §7 逐条现跑）：`0` 成功、`1` 通用失败、
`2` 用法/语法错、`126` 找到了但没法执行、`127` 命令不存在、`128+信号号` 被信号弄死
（`130`=Ctrl-C、`141`=SIGPIPE、`143`=SIGTERM）。还有一条最容易忘的：**退出码只保留低 8 位**，
所以 `return 300` 到外面看是 `44`（06 §4 把整条数轴排了一遍）。

## 表 3 · 管道、重定向与 fd（第 04 章）

| 我要…… | 靠得住的写法 | 现场 |
|---|---|---|
| stderr 一起进同一个文件 | `>f 2>&1`。**顺序不能换**：`2>&1 >f` 是把 stderr 留在原地，等于没接 | 04 §7 |
| 两种都收、不关心文件名 | `&>f`；追加 `&>>f`。POSIX 脚本里没有这两样 | 04 §8 |
| 只把结果给下游，噪声给我看 | `… 1>&2`（屏上 `echo 甲 >&2` 和 `echo 乙 1>&2` 同一条命令里一起上屏，两句话是同一件事）；反向临时换向屏上走的是 `exec 3>&2` 留底、`exec 2>&3 3>&-` 复原 —— `1>&3` 那种写法全书没上过屏 | 04 §8 |
| 关掉一个 fd | `exec 3<&-`；关了还读就是 `Bad file descriptor`（原文在第 9 节） | 04 §9 |
| 整个脚本的日志改道 | 开头一次 `exec >f 2>&1`：改的是**本 shell** 的 fd，而且是持久的 | 04 §10 |
| （反面）让故障彻底看不见 | 屏上加了 `2>/dev/null` 那一格：报错原文没了，`退出码=[2]` 一个字没变。`>/dev/null 2>&1` 那一格演的是顺手把正常输出也藏了（那条 ls 本来 `退出码=[0]`）。「藏住了为什么，藏不住失败了」是正文原话 | 04 §11 |
| 喂一段文本给命令 | `<<<`（一行）、`<<EOF`（要展开）、`<<'EOF'`（**不展开，写脚本首选**）、`<<-`（吃行首制表符） | 04 §12 |
| 一份数据既进文件又往下走 | `tee` / `tee -a`；`/dev/stdout` 那格演示了「输出重复」是怎么来的 | 04 §13 |
| `cat` 起头只为读文件 | 那是 UUOC：多一个进程、多一次读，第 14 节用管道段数证明给你看 | 04 §14 |
| 名字里带空格/换行的文件批量处理 | `find … -print0 \| xargs -0`，只有这一种。第 15 节屏上只跑到 `xargs -t echo`（没下手，切碎的文件还都在）；真删从第 16 节开始，删的是 `cp -a weird weird2` 出来的复制品，删完屏上 `还剩 0 个文件` | 04 §15 + 04 §16 |
| 让管道中间段的失败也算失败 | `set -o pipefail`。**副作用**：`… \| head -1` 会因为 SIGPIPE 变成假失败 | 04 §6 + 04 §19 |
| 把命令的输出当文件用 | `<(cmd)` 给的是 `/dev/fd/63` 这样的**文件名**，不是 stdin | 04 §20 |
| 比两个已排序结果 | `diff <(sort a) <(sort b)`；`>(…)` 那侧要等它写完才看得见全部内容 | 04 §21 |
| `\| grep` 时输出卡住不动 | 下游是管道时 stdio 默认**块缓冲**；`stdbuf -oL` 能救，但别当常规手段 | 04 §22 |
| 逐行读一个文件、同时往里写 | 自己占一个 fd：`exec 3< f` + `read -u 3`；或让 bash 自己挑号 `{var}>f` | 04 §23 |
| 重定向一整段但不想另起进程 | `{ …; } >f` 留在本进程；`( … ) >f` 另起一个 —— 变量还在不在当场见分晓 | 04 §24 |
| 绝不让 `>` 覆盖已有文件 | `set -C`（noclobber）；真要覆盖用 `>\|` | 04 §25 |

## 表 4 · 循环、读入与作业（第 05 章）

| 我要…… | 靠得住的写法 | 现场 |
|---|---|---|
| 遍历一份文件名单 | 循环体第一步先 `[ -e "$f" ]`：名单是**进循环前摊平的一次快照**，体里 `rm`/`touch` 改不到本轮 | 05 §4 |
| 通配可能匹配 0 个 | 先 `shopt -s nullglob`。默认档图案原样进循环（跑 1 轮）、`failglob` 在展开阶段当场炸且整条命令行作废 | 05 §5 |
| 数值循环、又不想起进程 | `for ((i=0;i<N;i++))`：只吃整数，`1.5` 是语法错误；写成非数字的名字当变量查 → 0 → 0 轮且不报错 | 05 §6 |
| 读一整行原文 | `IFS= read -r line`。少 `IFS=` 吃首尾和连续空白，少 `-r` 吃反斜杠 | 05 §9 + 05 §「一页纸」 |
| 判「读到东西了吗」 | `read` 的退出码问的是**撞没撞到分隔符**：空行 `0`、EOF `1`、`-t` 超时 `142` | 05 §9 + 05 §11 |
| 文件最后一行没有换行符 | `while IFS= read -r x \|\| [ -n "$x" ]` —— 整本书只背这一条修法 | 05 §12 |
| 循环体里要读 stdin（`ssh`、`cat`、再 `read`） | 它会跟外层 `read` 抢同一条流，只剩第一轮。三档：`< /dev/null`（`ssh` 用 `-n`）→ 分离到 fd 3 → 先 `mapfile` 进数组再 `for` | 05 §13 |
| 一次把整个流读进数组 | `mapfile -t arr`（`-s` 跳、`-n` 限量、`-O` 偏移、`-d ''` 按 NUL 切，配 `find -print0`）；`readarray` 是别名。**它只吃 `\n`，不吃 `\r`** | 05 §15 |
| 循环里改了变量，出来要拿 | 别让循环进管道：`while … done < <(cmd)` 最稳。`shopt -s lastpipe` 只救**最后一段**，且要求作业控制关着 —— 屏上只演了出厂位置那一格（`lastpipe` 报 `off`）和 `shopt -s lastpipe 之后 n=3`；「交互终端默认开着」是正文原话 | 05 §1 + 05 §14 |
| 在菜单里让人选 | `select` 是菜单不是遍历：变量装**名字**、`REPLY` 装**原始输入**；非法输入给空串、不报错、不退出；菜单走 **stderr**；喂不到输入 → 0 轮 + 退出码 1 | 05 §16 |
| 从两层循环里出去 | `break N` 往上穿 N 层；`continue N` 是把**第 N 层**推进下一轮（不是「跳过内层剩下的」）。层数写超不报错，只是悄悄少干活；bash 没有循环标签 | 05 §17 |
| 起后台并收尾 | `cmd &` + `wait`；`$!` 只是最后一个。数并发用 `jobs -rp \| wc -l`，别拿 `grep` 去切 `jobs` 的文本 | 05 §18 + 05 §20 |
| 放弃收尾权 | `disown`：账从作业表里删掉，进程照跑 | 05 §18 |
| 探一个进程活没活 | `kill -0` 的 `rc=1` 有两种含义（没这个进程 / 有但轮不到你）；它答的是内核视角，僵尸也算「在」 | 05 §18 |
| 等一个「迟早会好」的东西 | `until` 里写「等到什么就算了」，**并且必须同时写上界**；撞上界那一支要有自己的出口（非零退出／报警），否则「没起来」和「还在等」长得一样 | 05 §19 |
| 限并发 | 三行：起新任务**之前**每轮重新数闸门 → 超了就 `sleep` 一下 → 再 `&`。用 `wait -n` 就一定要接住它的返回值，不然失败的账没人记 | 05 §20 |
| 认「我自己」的进程 | `$BASHPID`；`$$` 在子 shell 里不变。屏上那条 ★ 是自己踩过的坑：`pa=$(BASHPID)` 想拿主 shell 的 pid，命令替换**本身就 fork**，量到的是那个子进程的 pid（跟 `$$` 永远不等） | 05 §21 + 01 §「命令速查表」 |

## 表 5 · 函数（第 06 章）

| 我要…… | 靠得住的写法 | 现场 |
|---|---|---|
| 从函数「返回一个数」 | `return N` —— 只有**退出码**这一条路，而且只保留低 8 位 | 06 §3 + 06 §4 |

| 递归 | 靠 `local` 每次都拿到一套；代价用**调用次数／深度**量，别用毫秒 | 06 §13 |
| 我要的是命令，不是同名的函数 | `type -a 名字` 先看谁占了名字，再用 `\name`、`command name`、`builtin name` 夺回来 | 06 §15 + 06 §16 |

## 表 6 · grep / sed / awk（第 07 章）

| 我要…… | 靠得住的写法 | 现场 |
|---|---|---|
| 选正则引擎 | `grep`（BRE）/ `grep -E`（ERE）/ `grep -P`（PCRE）：同一个模式三套下场，`+`、`(`、`{n,m}` 待遇各不同 | 07 §3 |
| 模式自己以 `-` 开头 | `grep -e '-xyz'` 或 `--`；否则它被当成开关 | 07 §4 |
| 数出现次数 | `grep` 给的是**整行**、数的是**行**：同一行出现两次只算 1。要逐个算用 `grep -o`（且 `-o` 不回头重叠） | 07 §5 + 07 §6 |
| 把 grep 用在判断里 | `if grep -q` —— `-q` 一命中就退，会少读输入，上游可能吃到 SIGPIPE | 07 §7 |
| 递归搜时挑文件 | 「搜什么内容」和「挑哪些文件」是**两套开关**：`--include` / `--exclude` / `-l` / `-z` 别混着记 | 07 §8 |
| 只改某些行、改第几处 | 地址先行：`sed -n '3,7p'`、`/RE/,/RE/p`、`s/…/…/2`；`&` 是整段命中、`\1` 是分组 | 07 §9 |
| 替换时大小写不敏感 | `s/…/…/I` 是 GNU 扩展，POSIX 不保证 —— 要跨机器就自己处理大小写 | 07 §10 |
| 就地改文件 | `sed -i` 的**四个代价**：它是删旧建新，inode 换了 —— 硬链接、原权限、正被别的进程写的那只手都不跟你走 | 07 §11 + 07 §12 |
| 网上抄的 `sed -i ""` | 那是 BSD 写法。本机 GNU sed 会把 `""` 当脚本、把真文件名当文件 → 当场报错或改错对象 | 07 §12 |

## 四段能直接抄的骨架

这四段是本章唯一「成段」的代码，每一段都由 `demo.sh` 第 5 节当场过一遍 `bash -n`。
它们只是**形状**，别当完整程序抄：语义正确性靠各章那一节的现场。

**1. 一个能上线的开头**（08 §3、08 §7、08 §15）

```bash
#!/usr/bin/env bash
set -Eeuo pipefail
IFS=$'\n\t'

tmpdir=$(mktemp -d "${TMPDIR:-/tmp}/mytask-XXXXXX")
cleanup() { rm -rf -- "$tmpdir"; }
trap cleanup EXIT
trap 'exit 130' INT
trap 'exit 143' TERM

cd -- "$tmpdir" || exit 1
```

**2. 逐行读名单，且体里的命令不抢 stdin**（05 §9、05 §12、05 §13）

```bash
while IFS= read -r host || [ -n "$host" ]; do
    [ -n "$host" ] || continue
    ssh -n -- "$host" 'hostname' < /dev/null
done < "${1:-hosts.txt}"
```

**3. 批量改名：计划 → 真跑 → 反向恢复**（10 §3、10 §8、04 §16）

```bash
shopt -s nullglob
plan=()
while IFS= read -r -d '' f; do
    plan+=("$f")
done < <(find . -maxdepth 1 -type f -name '*.txt' -print0)

printf '计划：%d 个\n' "${#plan[@]}"
for f in "${plan[@]}"; do
    printf '  %s -> %s\n' "$f" "${f%.txt}.md"
done

if [ "${1:-}" = "--go" ]; then
    for f in "${plan[@]}"; do mv -- "$f" "${f%.txt}.md"; done
    for f in "${plan[@]}"; do printf '  %s -> %s\n' "${f%.txt}.md" "$f"; done
fi
```

**4. 限并发三行**（05 §20、05 §18）

```bash
max=4
for job in "${jobs[@]}"; do
    while [ "$(jobs -rp | wc -l)" -ge "$max" ]; do
        sleep 0.05
    done
    run_one -- "$job" &
done
wait
```

## 一页纸（22 条，值得背下来）

```text
1  引用变量默认带双引号；"$@" 是转发参数的唯一姿势，$* 与不带引号的 $@ 都会切碎参数。
2  一道命令的顺序：花括号/变量/命令替换 → 算术 → 词分割 → 通配。引号只是把词粘回去。
3  {1..$N} 一个字都不展开。数值循环用 for (( ))：零进程、只吃整数。
4  不加引号 = 被词分割 + 再做一次通配展开。遍历名单第一句先 [ -e ]，因为名单是进循环前的快照。
5  通配 0 匹配有三档人生：默认原样进循环、nullglob 变 0 轮、failglob 当场炸且整条命令行作废。
6  read 的退出码问「撞没撞到分隔符」：空行 0、EOF 1、-t 超时 142。原样读行永远 IFS= read -r。
7  while read 会少跑最后一轮且不报错，唯一要背的修法写在条件里：|| [ -n "$x" ]。
8  体里任何读 stdin 的东西（ssh / cat / gpg / 再 read）都跟外层 read 抢同一条流：ssh 用 -n，或整体 < /dev/null。
9  循环一进管道就是另一个进程，赋值、数组、cd 全留原地。lastpipe 只救最后一段，且要作业控制关着。
10 重定向是按字读过去的：>f 2>&1 对，2>&1 >f 错。&> 是 bash 的缩写，POSIX 里没有。
11 $? 只是管道最后一段；全表在 "${PIPESTATUS[@]}"。pipefail 把中间段的失败升级成整条失败，副作用是 head 的 SIGPIPE 假失败。
12 <(cmd) 给的是文件名不是 stdin。要往回带状态用 while … done < <(cmd)，别让循环进管道。
13 退出码只保留低 8 位。0 成功、1 通用、2 用法、126 不可执行、127 不存在、128+信号 是被弄死。
14 空循环和跑完都是 0：轮数要自己数，别拿 $? 当「到底干没干活」的证据。
15 函数只有「退出码 + stdout」两条通道：码给调用方判，文本给命令替换吃，日志走 stderr。
16 local 是函数级（动态作用域），bash 没有块作用域；函数不会自动跨进程，export -f 只哄得住 bash。
17 set -e 有四位豁免（&& || 左侧 / 条件位 / ! / 被 if 调用的函数整个体），它兜不住「你以为它兜得住」的那些。
18 trap 的三个时间差：定义时展开、触发时会吞掉原本的退出码、清理自己被打断就留半截。EXIT 要配 INT/TERM 转发。
19 碰文件之前先测、临时名一律 mktemp、写完用同目录 mv 顶上；「测」与「写」之间的窗口真能被人插进一次改指。
20 grep 数的是行、sed 改的是行、awk 吃的是字段：三个工具的「单位」不一样，粘在一起时最容易错位。
21 就地改（sed -i）是删旧建新：inode 会变，权限与正被打开的那只手都不跟你走；BSD 的 -i "" 在本机 GNU sed 上是另一种事故。
22 能复现的才当证据：计数、顺序、布尔、退出码。pid、毫秒、inode、并发完成次序每跑必变 —— 一律不许当判据。
```

## 这章的坑（速查表自己也会骗人）

1. **这一页不能替代那一节。** 表里每行是「结论 + 出处」，不带现场。你要改一个正在跑的脚本，
   别只扫这一页 —— 按出处回那一节看一眼它到底是怎么响的。03 §14 那节「同一件事的几种写法实测差在哪」
   被压缩成一行之后，最容易丢的就是「差在哪」。
2. **出处的节号会随改版漂。** 所以 `demo.sh` 第 3 节是**当场解析标题**，不是背一张映射表。
   哪天你重排了某一章，这一页会直接报断链，而不是让你翻到空处。
3. **「骨架」四段是形状不是程序。** 第 4 段里的 `jobs` 和 `run_one` 都没定义，第 2 段会真的去连 `ssh`；
   它们只保证一件事：**语法过得了 `bash -n`**。
4. **`bash -n` 过得了 ≠ 跑得对。** 09 §9 把「不跑起来也能查出来的」分成三层，
   `bash -n` 只是最外那层。这一页里所有「必须真跑才知道」的结论，都是各章现场跑出来的，不是 `bash -n` 验出来的。
5. **别把这一页里的「唯一写法」当成我的偏好。** 它们都是被反例演过的：
   `{1..$N}`、`2>&1 >f`、`for f in $(…)`、`sed -i ""`、`$*` 转发 —— 每一条在后面那一章都有一处真实事故。

## 术语小抄

| 术语 | 这本书里的确切所指 |
|---|---|
| 内建 / 外部命令 | 内建由 bash 进程自己执行（不 fork）；外部命令要 `fork`+`exec` 一个真程序。`type -t` 给答案 |
| 条件位 | 出现在 `if`/`while`/`until` 条件、`&&`/`\|\|` 左侧、`!` 之后的命令位置 —— 那里的失败不触发 `set -e` |
| 名单快照 | `for x in <词表>` 的名单在进循环**之前**摊平一次；体里的改动改不到本轮 |
| fd | 进程手里的整数号头。`>f` 是 1、`2>` 是 2、`exec 3<` 是 3。重定向按字从左往右读 |
| 作业表 | 交互 bash 记自己后台任务的账（`jobs`/`wait`/`disown` 动的是它）。它不等于内核视角（`kill -0`） |
| 哨兵 | 往队列/管道里塞一个约定的结束标记来收尾读取方。10 §9 的五步里它属于「先出计划」那一环 |
| 掩码后的形状 | 把每跑必变的字段（pid、毫秒、inode 号、随机后缀）换成占位符之后剩下的那串字 —— 本书唯一拿来当证据的形态 |
